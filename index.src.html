API
Anam API key

Get this from your Anam dashboard at lab.anam.ai/api-keys — opens in your browser, not inside this app, so paste it back here after copying.

Green API credentials (WhatsApp)

Your own instance at console.green-api.com — this is what powers WhatsApp calling for your own account, separate from anyone else using this app. Paste your Instance ID and API Token joined with a colon, e.g. 710722741123:ac0f53a0d2ec...

Fal API key

Used for the Live Swap feature (real-time face/background swap). Get a key from your Fal dashboard at fal.ai/dashboard/keys — opens in your browser, not inside this app, so paste it back here after copying.
